# Snake Game 🐍
A classic Snake Game built with HTML, CSS, and JavaScript.

## Features
- Smooth snake movement 🐍
- Food generation 🍎
- Score tracking 🏆
- Game over screen 💀
- Background music 🎵
- Sound effects 🔊

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Play
- Use Arrow Keys to move the snake
- Eat food to grow bigger
- Avoid hitting walls and yourself
- Try to get the highest score!
